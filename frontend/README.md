# HomeCare Central Frontend — Milestone 2 Part 1

Part 1 screens: public application form, login, role-specific placeholder dashboards, HR applicant list/detail and hiring workflow, plus Admin user/role management.

## Run
1. Set the frontend API base URL in `.env.local` if your project requires it (default API origin is documented in `src/lib/api.js`).
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000
